# منصة عرض تطبيقات المطور أبو معاذ (Apps Showcase)

> موقع ويب عربي (من اليمين إلى اليسار) يعرض تطبيقات المطور أبو معاذ ويسهّل تحميلها: يجلب آخر الإصدارات وملفات APK مباشرة من مستودعات GitHub الخاصة به، مع مساعد ذكاء اصطناعي للإجابة عن أسئلة الزوار.

## ما هو الموقع؟

«منصة عرض التطبيقات» هي الصفحة الرسمية التي يجمع فيها المطور أبو معاذ تطبيقاته في مكان واحد: يتصفح الزائر التطبيقات، ويقرأ وصف كل تطبيق وميزاته، ويحمّل أحدث نسخة APK منه مباشرة من GitHub، دون الحاجة إلى البحث في كل مستودع على حدة.

## ماذا يفعل؟ وأهم الميزات

- **عرض التطبيقات:** بطاقات لكل تطبيق مع أيقونته ووصفه وتصنيفه.
- **تحميل مباشر:** جلب آخر الإصدارات وملفات APK مباشرة من مستودعات GitHub، مع عرض آخر إصدار وحجم الملف.
- **بحث وتصنيف:** البحث عن تطبيق، والتصفية حسب التصنيف (الكل، إسلامي، أدوات، تسوق، تطوير).
- **مساعد ذكاء اصطناعي:** مساعد مبني على Gemini يجيب عن أسئلة الزوار حول التطبيقات.
- **واجهة عربية كاملة:** تصميم عربي من اليمين إلى اليسار مع الوضعين الفاتح والداكن.

## كيفية الاستخدام

1. افتح المنصة في المتصفح.
2. تصفح التطبيقات أو ابحث عن تطبيق معين، أو صفِّ حسب التصنيف.
3. افتح بطاقة التطبيق لعرض تفاصيله وآخر إصدار له.
4. اضغط زر التحميل لتنزيل ملف APK مباشرة من GitHub، ثم ثبّته على جهاز أندرويد.
5. يمكنك سؤال مساعد الذكاء الاصطناعي في المنصة عن أي تطبيق.

## التقنيات المستخدمة

- **الواجهة:** React 19 مع Vite وTailwind CSS 4
- **الخادم:** Express ‏(server.ts)‏
- **الذكاء الاصطناعي:** Gemini API من جانب الخادم
- **البيانات:** جلب الإصدارات وملفات APK من GitHub API
- **الرسوم المتحركة:** Motion، والأيقونات Lucide

## التثبيت والتشغيل محلياً

```bash
git clone https://github.com/Ali-awwww/apps-showcase.git
cd apps-showcase
npm install
```

1. انسخ ملف `.env.example` إلى `.env`، واملأ المتغيرات المطلوبة، ومنها `GEMINI_API_KEY`.
2. شغّل خادم التطوير:

```bash
npm run dev
```

ولبناء نسخة الإنتاج وتشغيلها:

```bash
npm run build
npm start
```
